### 3.1 智能应用（/console/factory）

**两类应用**：
- **轻量应用**：仅靠一段系统提示词创建的对话机器人，快速创建
- **知识库应用**：基于私有数据定制问答（AI 客服场景），创建后不可逆（轻量可升级为知识库应用）

**应用配置七大模块**（齿轮图标进入，左配置右调试分屏，修改需保存生效）：

1. **基础信息**：名称、头像、应用类型、唯一应用 code、删除（不删除关联知识库）、轻量→知识库升级入口
2. **应用分享**：
   - 分享链接
   - **是否公开开关**：公开后其他用户可在应用广场对话，作者获得收益
   - 应用描述
   - **开场介绍**：首条消息，支持 Markdown；支持 `[]` 语法生成可点击引导问题
   - **问题推荐**：回复后自动生成递进式推荐问题（与对话历史相关、尽量命中知识库），支持 Web 调试、网站嵌入、渠道托管、API 接入
3. **模型与 Prompt 设置**：
   - 默认模型 + 对话可选模型（可切换）
   - 模型库：通用大模型（ChatGPT/Claude/Gemini/DeepSeek/Qwen/文心/豆包/Kimi/GLM/讯飞）+ 行业大模型（通义法睿法律）
   - **声音配置**：186 款预置音色 + 声音复刻专属音色，网页端语音播报、渠道端语音回复
   - **最大上下文长度**（不超过模型上限，含记忆轮次+应用设定+知识库命中+提问+回复，按 token 计）
   - **记忆轮次**（超出自动清除）
   - **温度**（知识库场景建议 ≤0.3）
   - **应用设定（系统提示词）**：附角色/目标/技能/工作流/注意五段式模板；支持 **一键优化**
4. **知识库配置**（仅知识库应用）：绑定知识库，按目录勾选，设置检索策略与未命中策略
5. **数据库配置**（仅知识库应用）：绑定内置/远程数据库
6. **插件配置**：默认自带若干插件（默认关闭），可添加
7. **高级配置**：转人工、拟人化

**使用方式**：网页端对话（支持语音模式）、渠道端接入、API 接入。

### 3.2 工作流（/console/workflows）

**定位**：可视化拖拉拽、零代码的流程型智能体编排。

**五大特点**：
1. 十余种节点任意组合，业务人员可读懂的流程图
2. 组合多应用的超级智能体（按用户意图选不同数字员工）
3. 定时任务触发（自然语言描述配置时间规则）
4. 主动渠道发送（任意节点输出主动发到指定渠道，做信息获取/社群运营）
5. 三种接入（自建部署、托管一键、API）

**节点全清单**：

| 分类 | 节点 | 说明 |
|---|---|---|
| 基础 | 开始/结束 | 必需 |
| 基础 | 大模型 | 调 LLM + 系统提示词 |
| 基础 | 智能体 | 调用已创建的轻量/知识库应用或超级助理 |
| 基础 | 知识库 | 检索指定知识库并输出 |
| 基础 | 插件 | 内置/自定义插件 |
| 基础 | 代码块 | Python / JavaScript |
| 分支 | 意图分支 | LLM 或 Jev 决策模型判意图 |
| 分支 | 逻辑分支 | 变量值逻辑判断 |
| 个性 | 固定回复 | 输出固定内容 |
| 个性 | 渠道发送 | 主动发送到指定渠道 |
| 个性 | 转人工 | 触发转人工并发提醒 |

**运行方式**：全流程运行、单节点运行、广场对话运行、定时自动运行。
**接入方式**：发布到广场、托管渠道接入、自建部署渠道接入、API 接入。

### 3.3 知识库（/console/knowledgeBase）

**组织方式**：
- 多级目录（最多 20 级），拖拽移动、"移动到"、批量管理（移动/删除）、按目录绑定应用
- 企业空间支持按目录授权数据范围

**四种知识导入类型**（同一知识库可混用）：
1. **文档**：pdf/docx/md/txt/单列 CSV，自动拆分加工
2. **问答（QA）**：双列 CSV 模板（question/answer）
3. **表格**：多列 Excel/CSV，可设参与索引的列
4. **网站导入**：单个/批量网址或 sitemap.xml，自动解析网页

**解析策略**（文档类）：
- 文本解析：仅文字
- 增强解析：文字+图片+表格（提取图片自动入素材管理）
- 智能解析：图像识别大模型，适合复杂表格/PDF 扫描件，15 积分/页

**分段策略**：
- 智能分段（默认，可设最大长度）
- 自定义分段（分段长度/多分隔符/分段重叠度）
- 层级分段（保留文档层级，适合 Markdown、网页、智能解析后的 Word/PDF/PPT）

**QA 检索策略**：同时检索问题和答案（范围广）/ 只检索问题（更精准）。

**表格导入细节**：默认 Sheet1、首行表头、合并单元格填左上值、列名可改（列名有语义解释作用）、可设索引列。

**网站导入细节**：批量独立网址（换行分隔）、sitemap 导入；可选提取子页面（多层递归）、提取图片；不支持网页标红提示；建议导入静态资源站。

**素材系统**：为语料附加图片/视频/文件（pdf/ppt/word/excel/csv/txt/md）、小程序卡片、微信号名片；命中语料时直接发出（需在提示词中加指令"直接发送链接"）。

**内容编辑**：文件列表查看/编辑/删除/单条新增，异步同步。

**检索策略配置**：
- 语义检索（相似度阈值 + 语义检索条数，默认 3）
- 增强检索（语义 + 全文关键词，全文条数默认 1，两者之和最大 10）
- 未命中策略：自由发挥 / 固定文案 / 转人工
- 展示知识库引用来源（文件名/网站名/网址，可单独设阈值）
- 查询改写（结合上下文补全问题，指代消解，额外检索一次）
- 结果重排

**检索测试**：模拟提问看相似度，支持语义/增强两种模式，辅助调参。
**定时同步**：网页和在线文档（飞书）每日自动同步，支持手动同步，内容变更才更新，sitemap 增量同步新页面。
**导入权益**（版本差异）：单次文件数 10/15/30、单文件 15/20/30MB、表格行数 2000/5000/10000、单次网页 10/20/30、sitemap 网页 20/50/100。

### 3.4 数据库（/console/database）

**两种库**：
- **内置库**：平台托管开箱即用；多张表，Excel 导入自动生成字段或手动定义字段；数据写入支持手动添加/文件导入/智能体对话
- **远程库**（专业版+）：连接 MySQL / SQLServer / PostgreSQL，自动加载数据表可选纳入管理；安全措施（加密传输存储、仅支持查询、IP 白名单/只读用户建议）

**关键设计**：数据库描述用于意图识别（判断是否调用数据库能力）；数据表描述、字段描述用于生成 SQL 和写入规则（枚举值要写进字段描述）。
**数据管理**：数据预览、手动新增/编辑、批量导入、导出。
**权限**：可控制用户使用时的操作权限（查询/写入等）。

**AI to SQL 能力**：
- 自然语言一键生成 SQL、分析文案、数据图表（折线/饼图/柱状，AI 自动选型可手动切换）
- 支持单表及多表 JOIN
- 对话页 Tab 切换：图表 / 表格明细 / SQL 语句
- **数据录入**：对话中智能提取字段值写入结构化数据（订单、客户画像等）
- 渠道端：图表以图片发出、明细以表格文件发出；支持企微/公众号/飞书/钉钉/微信
- API 接入返回分析文案 + 图表链接

### 3.5 插件（/console/plugins）

**原理**：对用户提问做意图识别（或关键词匹配）决策调用；已兼容 **MCP 协议**（MCP Server 一键转插件）。

**内置插件清单**（含触发与计费，复刻时按此列表实现）：

| 插件 | 能力 | 触发条件 | 价格 |

## 四、超级 AI 助理（Agent）

**双形态**：

| 维度 | 云端托管 | 桌面客户端（macOS/Windows） |
|---|---|---|
| 运行环境 | LinkAI 云电脑，7×24 在线 | 本机，跟随开关机 |
| 开始使用 | 控制台创建约 3 分钟 | 下载安装包登录 |
| 工作空间 | 云端独立空间 | 本机工作目录 |
| 可操作资源 | 云电脑文件/终端/浏览器 | 本机文件/终端/浏览器 |
| 多智能体团队 | 跨云电脑组队 | 团队数据在本机 |

**十大核心能力**：
1. 复杂任务规划（自主规划执行，持续思考调工具，可操作文件/终端/浏览器/定时任务）
2. 多智能体团队（@ 指定或自动委派）
3. 长期记忆（核心记忆+天级记忆，关键词+向量混合检索，"梦境蒸馏"每日自动整理）
4. 知识库（Agent 自主构建维护，自动写入、混合检索、文件树与知识图谱可视化）
5. 技能系统（Skills 引擎，对话创建自定义技能，从 Skill Hub/GitHub/ClawHub/LinkAI 一键安装）
6. 自主进化（空闲后自动复盘：优化技能、处理待办、沉淀记忆知识）
7. 多模态消息（文本/图片/语音/文件解析处理生成发送）
8. 多模型接入（OpenAI/Claude/Gemini/DeepSeek/MiniMax/GLM/Qwen/Kimi/Doubao）
9. 多端部署（微信/飞书/钉钉/QQ/企微/网页）
10. 平台资源可安装为技能（应用、知识库、数据库、工作流）

**对话命令与控制台**：斜杠指令管理配置/技能/记忆/知识库、多会话管理。
**使用场景**：内容运营、行情分析、Vibe Coding（GitHub 操作+前端设计全流程）、企业提效、本地文件与数据处理。

## 五、内容创作平台 Studio（studio.link-ai.tech）

1. **无限画布**：文本/图片/视频/音频/文件多类型节点，自由拖拽连接编排；框选模式运行整个画布或单个流程；批量下载画布图片/视频
2. **音频节点**：平台语音合成+音色库（含复刻音色），试听、长文本自动分段合成、方括号标注语气（如 `[惊喜地]`）
3. **内容创作 Agent**：对话描述需求→从文案脚本、分镜图片到视频成片配音全流程
   - **先确认再生成**：图片/视频以生成卡片呈现，提示词/模型/参数可改，确认后才执行计费
