### 风险点 / 下游注意
1. **SDK 打包缺口（需 contract-engineer 处理）**：`packages/sdk-ts` 的 `console.ts`/`service.ts` 未 re-export models 类型，且 package.json exports 的 "." 指向不存在的 `src/index.ts`。前端现经 alias（vite/tsconfig paths）直消费 `src/models/*` 生成物；建议 SDK 侧补 `src/index.ts` 统一导出
2. **契约 Page.items 为通用 object**：`/apps` 列表 items 无具体形态（`{[key:string]: unknown}`），前端用运行时守卫收窄为 App（features/app/api/app-api.ts narrowApps）；若契约后续细化 items schema，可删守卫
3. **契约 App 无 code 字段**：截图卡片上的 `code:dWh..` 标识位以 `id` 等宽小字代替
4. **保存为两段式**：契约无"单接口收全部配置"，整页保存 = PATCH /apps/:id（基础信息）+ PUT /apps/:id/config（七件套），顺序调用；跨服务一致性需平台侧注意
5. **pnpm 12 构建脚本策略**：`pnpm install` 报 ERR_PNPM_IGNORED_BUILDS（esbuild/msw 等）；本地已 `pnpm rebuild esbuild msw vue-demi @scarf/scarf` 可构建。建议 devops 在根 package.json 增加 `pnpm.onlyBuiltDependencies` 或 CI pin pnpm 9；另 pnpm 12 安装会重写 pnpm-lock.yaml 并剔除 apps/docs、apps/web-marketing 的无 package.json importers（既有库存量问题，需 marketing/devops 关注）
6. **jsdom 测试注意**：Element Plus 2.14 以 `aria-disabled` 表达禁用态；`structuredClone` 无法克隆 Vue reactive 代理（DataCloneError），store 深拷贝用 JSON 往返；Node fetch adapter 需绝对 baseURL（测试环境已处理）
7. **双执行体痕迹**：本单经历第二执行体并发落盘（commit 02fa261~1c9b1fc），袁台已逐文件核对收敛；当前工作区为收敛后状态
