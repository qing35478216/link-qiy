## 交付说明

### 改了什么（分支 feat/T-003-apps）
四层实现（api → services → domain ← infra）：

- **domain/**（纯 Python）：`apps.py`（App 聚合、AppType、七件套值对象、全量替换/快照/回滚规则、领域异常）、`app_repositories.py`（AppRepository/AppVersionRepository 协议，tenant_id 进签名）、`pagination.py`（cursor keyset 编解码纯函数）、`quota.py`（四档应用数矩阵/徽标/QuotaSummary 值对象）、`events.py` 增补 AppPublished/AppUnpublished
- **services/**：`app_service.py`（CRUD + 配置 PUT 全量替换 + 版本快照/回滚 + 公开开关事件 + 创建前配额校验）、`quota_service.py`（面板数据，walletBalance/usage 占位待 T-007）
- **infra/**：`models.py` 增补 apps/app_versions 两表；`app_repo.py`（双仓储 SQLAlchemy 实现，tenant 强制过滤 + keyset 分页）；`app_config_codec.py`（七件套 ↔ JSON 编解码）
- **api/**：`apps.py`（契约 Apps 段 11 个端点）、`quota.py`（GET /quota/summary）、`schemas.py` 增补（App/AppConfig/Page/Quota 模型，全部 extra="forbid"）、`errors.py` 增补 AppError→400/403/404 映射、`deps.py`/`main.py` 接线
- **alembic/**：`0002_apps` 迁移（up/down 双向验证通过）
- **tests/**：domain 4 组 + infra 1 组 + api 1 组，共 158 用例（含 T-002 全部）

### 风险点
1. **PUT 全量替换是隐式破坏性语义**：契约 v0.1.1 明示"未提供段落视为清空"，前端必须整段提交；v0.2 PATCH 部分更新前，控制台保存逻辑要按全量组装（已在与前端约定清单注明）
2. **回滚为 append-only 新版本**（非"回到旧版本号"）：版本号单调递增，历史不可变；若产品要求"当前版本号回退到目标号"需契约澄清
3. **应用数配额服务端默认执行**（基础版 3/标准 10/专业 30/企业不限，docs/01 矩阵）：契约未定义该错误码，用了 APP_LIMIT_EXCEEDED→403；若契约后续定义专属错误码需对齐
4. **walletBalance/usage 为 0 占位**：计费域 T-007 落地前，前端勿将其当真实余额展示
5. **沙箱限制**：pytest 需 `--basetemp`；架构守卫自测（tests/architecture/test_guard_effective.py）曾硬编码 services/users.py 不存在文件名导致 FileNotFound，已改为层内首文件动态选取
6. **sqlite 冒烟替代 PG**：接 PG16 后需重跑 /apps 全链路（时间列 aware 归一已处理）
